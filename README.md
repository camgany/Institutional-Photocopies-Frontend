# Página Web Fotocopias UPB 🏢💻 
## Acerca del proyecto 📋
El proyecto de práctica interna consiste en el desarrollo de una aplicación web para la gestión de solicitudes de fotocopiado en la Universidad Privada Boliviana (UPB). El objetivo principal es proporcionar un servicio eficiente y de calidad a los estudiantes, docentes y personal administrativo de la universidad, permitiendo realizar solicitudes de fotocopiado de manera rápida y sencilla. Además, se busca facilitar la gestión y supervisión de los pedidos por parte del personal encargado del servicio de fotocopiado.
El frontend del proyecto consiste en la parte de la aplicación web que se encarga de la interfaz de usuario y la interacción visual. El objetivo principal es proporcionar una experiencia de usuario fluida y amigable, tanto para los usuarios que realizan solicitudes de fotocopiado como para el administrador encargado de gestionar y supervisar los pedidos.

## Características principales 🚀
El frontend ha sido diseñado utilizando las mejores prácticas en desarrollo web y se ha implementado con tecnologías modernas y eficientes. A continuación, se describen las principales características del frontend:

- Páginas de acceso y seguridad: Se han desarrollado páginas de inicio de sesión y registro para permitir a los usuarios autenticarse en el sistema. Además, se ha implementado una función de recuperación de contraseña en caso de olvido. Estas páginas cuentan con validación de datos y medidas de seguridad para proteger la información confidencial.

- Interfaz de usuario intuitiva: La interfaz de usuario ha sido diseñada de manera intuitiva, con un diseño limpio y moderno que facilita la navegación y comprensión de las funcionalidades. Se han utilizado elementos visuales claros y consistentes, como botones, formularios y menús, para proporcionar una experiencia de usuario agradable.

- Vistas protegidas: Se han implementado vistas protegidas que requieren autenticación para acceder. Esto garantiza que solo los usuarios autorizados puedan realizar determinadas acciones, como enviar solicitudes de fotocopiado o acceder al panel de control del administrador.

- Formulario de solicitud de fotocopiado: Se ha creado un formulario de solicitud de fotocopiado para que los usuarios ingresen la información necesaria, como la cantidad de copias, si se requiere anillado, si es a color, entre otros detalles. Este formulario cuenta con validación de datos en tiempo real para garantizar que se proporcionen los datos correctos y completos.

- Panel de control del administrador: El administrador tiene acceso a un panel de control que proporciona una visión general de los pedidos realizados. Se han desarrollado gráficos y estadísticas que muestran datos relevantes, como la cantidad de pedidos por facultad, el número total de pedidos y los pedidos pendientes. Esto permite al administrador monitorear y gestionar eficientemente el servicio de fotocopiado.

- Visualización de pedidos detallados: El administrador puede ver todos los pedidos pendientes y, al hacer clic en un pedido en particular, se muestra una vista detallada con la información específica del solicitante, la fecha y hora de entrega, la cantidad de copias, entre otros detalles. Esto facilita la gestión y seguimiento de cada solicitud.

## Tecnologías utilizadas 🛠️
El frontend del proyecto ha sido desarrollado utilizando las siguientes tecnologías y herramientas:

- JavaScript: Para la implementación de funcionalidades interactivas y validación de formularios.
- React.js: Como framework de desarrollo de interfaces de usuario, permitiendo un enfoque de componentes reutilizables y una arquitectura escalable.
- React Router: Para la gestión de rutas y navegación en la aplicación.
- Material UI: Como librería de componentes visuales, proporcionando elementos de interfaz de usuario predefinidos y personalizables.
- Axios: Para la comunicación con el backend, permitiendo realizar peticiones HTTP.
- React Chart.js 2: Para la creación de gráficos y estadísticas.
- React Bootstrap Table 2: Para la creación de tablas con datos de los pedidos.
- React Export Excel: Para la generación de archivos Excel con los datos de los pedidos.
- React Icons: Para la utilización de iconos en la interfaz de usuario.
- React Router Dom: Para la gestión de rutas y navegación en la aplicación.

## Instalación y configuración 🔧
Para instalar y configurar el frontend del proyecto, se deben seguir los siguientes pasos:

1. Clonar el repositorio del proyecto en la máquina local, utilizando el siguiente comando:
```
git clone https://github.com/camgany/Institutional-Photocopies-Frontend.git
```
2. Abrir la carpeta del proyecto en un editor de código, como Visual Studio Code, y abrir una terminal integrada.
```
cd Institutional-Photocopies-Frontend
```
3. Ejecutar el siguiente comando para instalar las dependencias del proyecto:
```
npm install
```
4. Ejecutar el siguiente comando para iniciar la aplicación:
```
npm start
```
5. Abrir el navegador web y acceder a la siguiente URL:
```
http://localhost:3000/ o a la URL que se indique en la terminal
```
6. También se puede acceder a la aplicación en la siguiente URL:
```
https://main--fotocopias-upb-lp.netlify.app/
```
